# oddments

Living web components drawn from paintings, plates, water, cloth and stone, free to take.
See them all at **https://socialacolyte.github.io/stylefeatures/**.

```sh
npx oddments                 # list every piece
npx oddments add koi-pond    # copy one into ./oddments/koi-pond/
npx oddments open koi-pond   # its page on the site
```

Each piece is a self-contained folder: `demo.html`, the module, its stylesheet, a README, its
assets and a `CREDITS.md`. No build step. Some are also on npm as `@oddments/<piece>`.

The code is MIT. The paintings, plates and sounds keep their own licences, credited with each piece.
